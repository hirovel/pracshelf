命令行与常见问题

启动

在项目根目录运行。首次安装先执行 uv sync，以后使用：

uv run collect serve

只启动服务、不打开浏览器：uv run collect serve --no-browser。端口已占用时用 --port 8767。

官方 CLI 备用登录

若已经安装官方 Codex CLI，可在终端检查和登录：

codex login status
codex login

完成官方浏览器登录后，回到此页重新检查。使用不同 CODEX_HOME 或系统用户时，登录可能不共享；服务和终端需使用同一环境。网页路径使用 SDK 自带运行时，不要求另外安装全局 CLI。

没有指定模型

检查结果仅列出当前运行时的模型目录。本项目配置默认 gpt-6.1-sol / high；缺少该模型或档位时不自动替换。可在启动前显式配置 LIBRARY_CODEX_MODEL 与 LIBRARY_CODEX_EFFORT，再检查。

登录或检查失败

查看下方检查记录，再检查网络后重试。取消只停止本次等待，不退出已有账号；官方凭据不经过此页面的表单。

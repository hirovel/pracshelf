从资料到自己的笔记

以下内容是合成示例，用于说明阅读流程。没有采集真实来源、调用模型或保存笔记，不属于精选文章。

  1. 先看标题、简介、作者和日期，选择要保存的链接。
  2. 保存原始响应，从快照整理完整原文。
  3. 明确启动一次全文价值判断与核心提取；查看原文依据。
  4. 需要中文时启动可选翻译，再阅读并亲自写笔记。
  5. 导出自己保存的 Markdown 笔记。

合成示例：先给编码助手一个可验证的任务

示例原文：把修改限定在一个行为，提供输入、预期结果和现有约束，完成后检查实际变化。

示例核心

先明确可以验证的结果，再让助手修改。以上只是演示内容，没有模型质量验证。
